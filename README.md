# SK-pilot (СК-пилот) — система ежедневных сводок строительного контроля

**Версия:** 1.5  
**Автор:** Vladislav Nikonenko (идея и разработка)  
**Лицензия:** Проприетарная — см. [LICENSE](./LICENSE)

---

## Описание

СК-пилот — веб-приложение для инженеров строительного контроля. Позволяет вести
ежедневные сводки по объектам: персонал, входной/операционный/приёмочный контроль,
замечания, предписания, фотофиксация, ИД/КС. Администратор видит сводки всех
инженеров в одном интерфейсе.

Компаньон системы **TeamJect** (`app.teamject.com`) — предписания и акты.

---

## Стек

- **Backend:** Python, Flask, gunicorn
- **База данных:** SQLite (WAL-режим)
- **Frontend:** Vanilla JS, три SPA-страницы (без фреймворков)
- **Деплой:** nginx (reverse proxy) + gunicorn

---

## Локальный запуск

```bash
pip3 install flask flask-cors
python3 app.py
```

Приложение доступно на `http://localhost:5000`.
