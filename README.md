# Пилот — Система ежедневных сводок
## Инструкция запуска (шаг за шагом)

### Требования
- Python 3.9+ (проверь: `python3 --version`)
- pip (обычно установлен вместе с Python)

---

### Первый запуск

**Шаг 1.** Открой терминал (Terminal / командная строка) и перейди в папку проекта:
```bash
cd /путь/к/папке/pilot
```

**Шаг 2.** Установи зависимости (один раз):
```bash
pip3 install flask flask-cors
```

**Шаг 3.** Запусти сервер:
```bash
python3 app.py
```

Ты увидишь:
```
✅ База данных инициализирована
🚀 Сервер запущен: http://localhost:5000
```

**Шаг 4.** Открой браузер и перейди на:
```
http://localhost:5000/api/objects
```
Должен появиться JSON с объектом ЖК «Окла».

---

### Ежедневный запуск
Просто запускай `python3 app.py` из папки проекта.
Остановить сервер: `Ctrl+C` в терминале.

## Структура API

### Объекты
| Метод | URL | Что делает |
|-------|-----|------------|
| GET | /api/objects | Список всех объектов |
| POST | /api/objects | Создать новый объект |
| GET | /api/objects/1 | Детали объекта (с корпусами, подрядчиками, инженерами) |
| PATCH | /api/objects/1 | Обновить объект |
| POST | /api/objects/1/sections | Добавить корпус/блок |
| POST | /api/objects/1/contractors | Добавить подрядчика |
| POST | /api/objects/1/assign_user | Назначить инженера на объект |

### Сводки
| Метод | URL | Что делает |
|-------|-----|------------|
| GET | /api/objects/1/reports | Список сводок по объекту |
| POST | /api/reports | Создать сводку |
| GET | /api/reports/1 | Полная сводка со всеми разделами |
| POST | /api/reports/1/submit | Сдать сводку (статус → submitted) |

### Разделы сводки
| Метод | URL | Что делает |
|-------|-----|------------|
| POST | /api/reports/1/personnel | Добавить запись по персоналу (можно массивом) |
| POST | /api/reports/1/input_control | Добавить запись входного контроля |
| POST | /api/reports/1/remarks | Добавить устное замечание |
| PATCH | /api/remarks/1/close | Закрыть замечание |
| POST | /api/reports/1/prescriptions | Добавить ссылку на предписание из TeamJect |
| POST | /api/reports/1/meetings | Добавить совещание |
| POST | /api/reports/1/photos | Загрузить фото (multipart/form-data) |
| PATCH | /api/photos/1 | Обновить подпись к фото |

### Мониторинг (для руководителя)
| Метод | URL | Что делает |
|-------|-----|------------|
| GET | /api/objects/1/open_remarks | Все открытые устные замечания по объекту |
| GET | /api/objects/1/activity | Активность инженеров сегодня (заполнили ли сводку) |
